4. POLÍTICA DE BRANCHES E PULL REQUESTS (BRANCHING STRATEGY)
--------------------------------------------------------------------------------
- Branch principal: `main` (código estável para entregas)
- Branch de desenvolvimento: `develop` (integração contínua)
- Branches de funcionalidades: `feature/US_AXXX-breve-descricao`
- Branches de correção: `bugfix/issue-descricao`

Regras de Proteção de Branch (Configurar no GitHub -> Settings -> Branches):
1. Exigir Pull Request (PR) antes de fundir (merge) em `main` e `develop`.
2. Exigir pelo menos 1 aprovação (code review) de outro elemento do grupo.
3. Não permitir `force push` no branch `main`.

## Sobre o Projeto
A plataforma **ALFAS** tem como objetivo promover a literacia em saúde junto dos jovens (3.º ciclo e ensino secundário). O sistema disponibiliza workshops, webinars, questionários de diagnóstico (pré) e finais (pós), além de um sistema de gamificação com atribuição de badges e certificados.

## Como Executar o Projeto Localmente

### Pré-requisitos
- Node.js (v18+)
- Python (v3.10+)
- MySQL Workbench ou SQL Server

### Frontend (React)
```bash
cd src/frontend
npm install
npm start
```

### Backend (Flask)
```bash
cd src/backend
python -m venv venv
source venv/bin/activate  # No Windows: venv\Scripts\activate
pip install -r requirements.txt
python run.py
```
