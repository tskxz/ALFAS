O consórcio ALFAS (Alfabetização em Saúde) pretende criar uma Plataforma de Literacia em Saúde para Jovens, baseada numa aplicação web que disponibiliza webinars e workshops sobre várias áreas da saúde, acessíveis mediante registo. O acesso a cada recurso formativo é enquadrado por um questionário de diagnóstico, respondido previamente, e por um questionário final, respondido posteriormente, o que permite avaliar o progresso de aprendizagem. A esta componente junta-se uma perspetiva de gamificação, com atribuição de badges e certificados, e uma biblioteca virtual com publicações, recursos, notícias, agenda de atividades e destaques da semana.
